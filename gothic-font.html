Several capitals in the regular Fraktur set come from the older Letterlike Symbols block, which is why their code points do not form one uninterrupted range.

Numbers do not have a matching Fraktur digit set here, so ordinary digits remain unchanged.

Terminology

Gothic vs Blackletter vs Fraktur vs Old English

Gothic font, blackletter font, Fraktur font, and Old English font are often used interchangeably in casual searches, but they are not exact synonyms.

Term Meaning on This Page
Gothic font A broad phrase for dark, medieval-looking, or blackletter-style text.
Blackletter A broad historical lettering and type family with dense, broken-looking forms.
Fraktur A blackletter tradition and the name used for the relevant Unicode mathematical alphabets.
Old English A common online label for related ornate blackletter looks.

This Gothic font generator uses Mathematical Fraktur Unicode for its two base conversions and clearly labels decorative alternatives.

Unicode and Rendering Limits

A Gothic font result may not look identical everywhere.

Platforms can restrict special characters, fonts can lack a glyph, and screen readers can interpret mathematical symbols differently from ordinary Latin letters.

The generator uses characters identified in Unicode as Mathematical Fraktur and Mathematical Bold Fraktur. For normal documents and finished graphic design, a properly licensed blackletter typeface is more appropriate than Unicode substitutions.

Source-backed limits

What the Unicode Sources Say

The Gothic font generator uses characters that the Unicode names list identifies as Mathematical Fraktur; the list notes that this style is sometimes known as black-letter. Unicode’s Latin and Cyrillic FAQ also explains that, for ordinary nonmathematical text, Fraktur is normally a font style of regular Latin letters. That is why this page describes its output as Unicode symbols for copy-paste display text rather than a substitute for a licensed typeface.

Gothic Font FAQ

What is a Gothic font generator?

A Gothic font generator changes ordinary Latin letters into Fraktur-style Unicode symbols that can be copied as text.

Can I copy and paste Gothic font text?

Yes. Copy any Gothic font result and paste it into a field that accepts those Unicode characters. Test it in the destination app because rendering rules vary.

Is this a downloadable Gothic font?

No. The Gothic font generator returns Unicode text, not a TTF, OTF, CSS webfont, or installable typeface.

Is this also an Old English font generator?

The phrase “Old English font generator” is often used online for a similar blackletter-style copy paste task. This tool specifically uses Mathematical Fraktur Unicode and labeled decorative styles.

What are Gothic-style fonts called?

Blackletter is the broad historical category. Fraktur is one blackletter tradition and is also the name used for the Unicode mathematical alphabets used by this generator.

Can I use Gothic font text for Discord or gaming names?

Often, yes. Gothic Unicode can work in display names and profile text, but each platform can restrict special characters. Test the final Gothic text first.
