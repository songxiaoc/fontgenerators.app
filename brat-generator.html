What the Brat Generator Makes

The Brat Generator is an image-making tool.

Type a phrase, choose the look, and export the visible canvas. The result is a flattened static graphic, so the background, narrow lettering, blur, and pixelated edges remain together after export.

The editor supports:

  • Background presets
  • Custom background colors
  • Custom text colors
  • Lowercase text
  • Text size adjustment
  • Blur
  • Pixelation
  • Center alignment
  • Right alignment
  • Justified alignment
  • Square, vertical, and widescreen output
  • PNG, JPEG, and WebP downloads

The current tool does not create video, lyric animation, mirror effects, or editable font files.

How the Preview Builds the Look

The browser preview narrows and softens the lettering, with optional blur and pixelation.

Its fallback font chain starts with Arial Narrow when available, then uses browser-safe sans-serif alternatives.

Because browser font availability can vary, small visual differences can appear across devices. For the source treatment, licensing context, and Canva or CapCut workflows, read the font treatment guide.

Brat Generator FAQ

Is the Brat Generator free?

Yes. The Brat Generator is free to use, requires no account, and adds no watermark.

What font does the Brat Generator use?

The canvas first tries Arial Narrow when available, then uses browser-safe sans-serif fallbacks and compresses the text horizontally.

Do I need to install anything?

No. The Brat Generator runs in the browser and exports an image without installing a font or app.

What goes to the clipboard?

The copy button copies the rendered PNG image, not editable text.

Can I use the green preset?

Yes. The built-in green preset is #8ACE00 with dark text by default.

Can I make a brat image with a transparent background?

Yes. Choose the Transparent preset and export PNG or WebP to preserve transparency. JPEG does not support transparent pixels.

Does the Brat Generator work on mobile?

Yes. The editor works in current mobile and desktop browsers. Image clipboard support varies by browser, but image download remains available.
